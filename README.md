# Teamora – manager performance platform (demo)
Plain HTML, CSS and JavaScript. Open `index.html`. No install needed.

| File | Purpose |
|---|---|
| index.html | Page structure |
| css/style.css | Styling (colors are variables in `:root`) |
| js/app.js | 9 labelled parts: data, goals, analytics chart, profile, donut + calculator, pricing, FAQ, forms |

Customize sample data at the top of `js/app.js`. Everything is fictional; login and forms are mock only and nothing is sent anywhere.
